# 扣子 OZON-OGL 工作流使用说明

导入 `Workflow-OZON-OGL.zip` 后，在“开始”节点的 `input` 中传入 JSON 字符串。

示例与原 Excel“定价核算”页当前样例一致：

```json
{
  "product_name": "示例：14寸硬壳化妆箱",
  "sale_price_cny": 62,
  "purchase_cost_cny": 13,
  "domestic_misc_cny": 0,
  "commission_rate_pct": 9,
  "return_rate_pct": 10,
  "withdrawal_rate_pct": 1.2,
  "ads_rate_pct": 0,
  "last_mile_rate_pct": 2,
  "weight_g": 450,
  "length_cm": 0,
  "width_cm": 0,
  "height_cm": 0,
  "exchange_rate_rub_per_cny": 12.6,
  "target_margin_pct": 30
}
```

百分比支持两种形式：`9` 和 `0.09` 都表示 9%。未填写的默认值来自“费率参数”页：

- RFBS 佣金：10%
- 退货/取消：3%
- 提现/结汇：1.2%
- 广告：5%
- 尾程：2%
- 汇率：12.6 RUB/CNY
- 目标销售利润率：30%

类目 RFBS 佣金应使用 Excel“类目佣金”页搜索后逐品填写。费率、汇率和 OGL 报价会变化，请以更新后的 Excel 为准同步修改代码节点。
