IMAGE ASSET DELIVERY

阿里云 OSS / CDN

第三阶段完成后，将 AI 图和翻译图复制到自有 OSS，再把稳定 HTTPS 地址提交给 Ozon。保存时会上传一张 1×1 验证图；AccessKey Secret 仅保存在服务器且永不回显。

填写地域 Endpoint，不要包含 Bucket 名称。
必须使用浏览器和 Ozon 均可直接访问、无需签名且证书可信的 HTTPS 地址。
建议创建仅允许当前 Bucket PutObject 的 RAM 子账号；如需从资产库清理孤儿图片，再增加 DeleteObject 权限。不要使用阿里云主账号 AccessKey。Bucket 需允许对象设置为 public-read，或配置能公开回源的 CDN。
