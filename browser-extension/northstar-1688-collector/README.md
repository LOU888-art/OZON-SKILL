# Northstar 1688 商品采集插件

## 安装

1. 解压 ZIP 到电脑中的固定文件夹。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择解压后的 `northstar-1688-collector` 文件夹。

## 使用

1. 在浏览器中打开并登录 Northstar ERP。
2. 登录 1688，打开 `detail.1688.com/offer/...html` 商品详情页并刷新一次，等待规格、价格和运费加载完成。
3. 点击插件，首次填写 ERP 的 HTTPS 网址；插件会自动记住，之后直接点击“读取当前1688商品”。
4. 在预览中取消不想上架的 SKU，点击“发送到ERP第一阶段”。
5. 回到 ERP，从第二阶段继续类目映射和上架流程。

插件从页面加载开始读取当前登录用户可以正常看到的接口响应、组件状态和页面内容；新版页面没有暴露结构化 SKU 时，会逐项点击规格按钮核对实际价格与库存，但不会下单或加入购物车。插件不绕过登录、验证码、风控或访问权限。发送前请核对完整 SKU 数、各 SKU 采购价和运费；读取不完整时插件会阻止发送。1688页面结构更新后，解析规则可能需要同步升级。

0.3.4 起优先读取 1688 页面公开给当前登录用户的 `context`/初始化商品模型，支持对象或数组形式的 SKU 映射；结构化 SKU 缺少价格或库存时，会逐项选择页面规格并使用当前交易区显示的真实值补齐。采集器不再只按 SKU 数量判断接口结果是否正确，还会核对每条规格值能否覆盖页面选项；单规格商品会按页面选项逐项重建 SKU，并将各自按钮图片绑定为 SKU 主图。阿里 CDN 的 60×60、100×100 等规格缩略图会还原为供应商原始高清图片地址，避免ERP放大后模糊。页面存在多张不同规格图但最终绑定不足时会阻止发送。插件不会用虚构库存补齐缺失数据，也不会把规格选项盲目组合成不存在的 SKU。
